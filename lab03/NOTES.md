git diff - показывает различия между версиями: рабочей директорией, индексом, коммитами.



git show - показывает содержимое одного объекта: обычно коммита.



git log - показывает историю коммитов.



git log -S - ищет коммиты, где менялось количество вхождений заданной строки (кто добавил/удалил текст).



git blame - показывает, какой коммит и автор последний раз меняли каждую строку файла.



git restore <файл> — восстанавливает файл из индекса (staging area).

Если файл не был git add, он вернётся к состоянию последнего коммита.

Ваши незакоммиченные правки в рабочей директории пропадут.



git restore --source=<коммит/ветка> <файл> — берёт версию файла из указанного источника и кладёт её в рабочую директорию.

Ваши текущие правки в этом файле тоже пропадут, но вы получите не последний коммит, а версию из выбранного источника.
